# Document Studio 4.0.0

Tag suggestion: `v4.0.0`

Experimental visual site builder: import HTML and small local supporting files, inspect the import report, edit the sandboxed canvas, use the page tree and breadcrumb, insert simplified HTML blocks, extract reusable components, and add mobile/tablet overrides. Source, history, and local autosave remain connected. Scripts and external resources are separately opt-in, and direct canvas editing is disabled while scripts run. The importer and component extraction have important limits; see README.md. Document branding remains optional and off by default.
